# Spot the Secret! — 초등 영어 6학년 도입 수업용 웹앱

## 바로 실행하기
1. `Spot_the_Secret_완성형_웹앱.html` 파일을 내려받습니다.
2. 파일을 더블클릭하여 Chrome/Edge 등 브라우저에서 엽니다. **인터넷 연결이나 서버 설치가 필요 없습니다.**
3. `미션 시작`을 누르면 학생용 5단계 수업을 바로 진행할 수 있습니다.
4. `교사용` 메뉴에서 이미지 변경, 정답 영역 추가/삭제, 교과서 영어 표현 변경, 저장/불러오기를 할 수 있습니다.

## 포함된 도입 수업
- 출처: 사용자가 제공한 PDF '초_영어6(김태은)_교과서-12단원(커버).pdf', 172~173쪽
- 단원: We Should Save the Earth!
- 172쪽: 컵 사용 / 전등 끄기 / 물 잠그기
- 173쪽: 종이 재사용 / 계단 이용 / 캔·병 재활용
- 진행: 차이점 찾기 → 공통점 추론 → 좋은 행동 선택 → 영어 표현 추측 → 제목 공개

## 제작 기능
- **교사용 > 그림 자료 교체**: JPG/PNG/WebP의 A/B 비교 그림을 업로드할 수 있습니다.
- **교사용 > 정답 영역 편집**: 원본 그림 위를 드래그하여 클릭 정답 범위를 추가합니다.
- **교사용 > 행동 및 영어 표현 편집**: 좋은 행동 정답(A 또는 B), 표현과 한국어 뜻을 수정합니다.
- **교사용 > 저장 및 공유**: 이 브라우저의 localStorage에 저장하거나 JSON 파일로 내보내고 가져옵니다.
- 브라우저 저장소가 초기화되거나 다른 컴퓨터로 옮길 때는 **반드시 JSON 파일을 내보내 백업**하세요.

## 범위와 제한
- 본 버전은 **전자칠판/한 대의 컴퓨터에서 교사가 진행하는 완성형 오프라인 웹앱**입니다.
- AI가 새로운 그림을 자동 생성하거나 여러 학생 기기를 실시간 동기화하는 기능은 포함하지 않습니다.
- 새로운 PDF 파일을 웹앱 안에서 직접 변환하는 기능은 포함하지 않습니다. PDF를 PNG/JPG로 저장해 업로드하세요.
- 기본 이미지의 행동 변화는 교육용 데모를 위한 합성 작업입니다. 실제 수업 전에 교사가 정답·표현 적합성을 확인해 주세요.
- 교과서 그림은 사용자가 제공한 자료를 기반으로 하며 공개 웹사이트에 재배포할 때 저작권 이용 범위를 확인하세요.

## 웹 호스팅
`index.html`, `data.js`, `app.js`, `style.css`를 같은 폴더에 두면 GitHub Pages에서도 실행됩니다. `assets/`는 원본 편집용 참고 파일로 포함했습니다.
